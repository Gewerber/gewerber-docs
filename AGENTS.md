# AGENTS.md — gewerber-docs

Public technical documentation for the Gewerber open-core platform.

## Contents

- `TECHNICAL_SPECIFICATION.md` — architecture, endpoints, database schema, module breakdown
- `ROADMAP.md` — public development phases and OSS deliverables
- `README.md` — index

## Conventions

- This is the **public** documentation. Keep it sanitized — no internal/business details (those live in the private `gewerber-business` repo).
- Use absolute URLs when linking to other Gewerber repositories (cross-repo relative links break on GitHub):
  `https://github.com/Gewerber/<repo>/blob/main/<path>`
- When new repositories or modules are added, update the relevant tables here and in `.github/ORGANIZATION.md`.

## Open-Core Boundary

Document only the open-source core. Closed modules may be listed at a high level but must not leak implementation details.
